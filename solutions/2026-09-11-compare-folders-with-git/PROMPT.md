# 可直接复制给 Codex 的提示词

```text
请使用 Git 的 git diff --no-index 比较我指定的两个文件夹，但保持只读，不创建 Git 仓库，也不修改任何文件。

旧文件夹：请替换为实际路径
新文件夹：请替换为实际路径

要求：
1. 先确认两个路径都是目录，并记录比较前的文件数量；不要扩大到目录外。
2. 从两个目录的共同父目录运行命令，并只传入相对目录名，避免输出个人绝对路径。
3. 第一遍只运行 --name-status，第二遍只运行 --stat；同时加上 --no-ext-diff、--no-renames 和 --no-color。
4. 只汇总新增、修改、删除的相对文件名和数量。文件名如果包含姓名、项目名或其他隐私，先脱敏再汇报。
5. 不显示文件内容，不读取 .env、凭据、Cookie、令牌、私钥或其他秘密原文。
6. 退出码 0 表示“没有差异”；退出码 1 且输出为正常差异清单时表示“发现差异”。如果输出包含 `error:`、路径不可访问等错误文字，即使退出码也是 1，也要按命令错误处理。
7. 只有我明确指定某个普通文本文件后，才显示该文件的详细差异；详细差异仍需隐藏秘密值。
8. 完成后再次核对文件数量和哈希，确认比较没有修改文件，也没有创建 .git 目录。
```
