# 可直接复制给 Codex 的提示词

```text
请先用 ripgrep（rg）在当前项目中定位与下面目标相关的文件和代码，不要立刻修改文件。

目标：在这里填写报错文字、函数名、配置项或要查的问题。

执行要求：
1. 先运行 rg --files 判断可搜索范围，再设计最小、最具体的搜索词。
2. 优先在当前项目内搜索；不要搜索整个磁盘、用户目录或项目外路径。
3. 默认尊重 .gitignore。只有确有必要时才搜索隐藏文件，并始终排除 .git 目录。
4. 不显示令牌、密码、Cookie、邮箱、个人路径或其他秘密原文；如果命中，只报告文件路径、行号、风险类型和脱敏摘要。
5. 把“没有匹配”（rg 退出码 1）与“命令执行错误”区分开。
6. 汇报使用的搜索条件、命中的文件和行号、你据此得出的结论，以及仍未验证的范围。
7. 在我明确同意修改前，只读分析，不编辑、不删除、不安装任何内容。
```

如果 `rg` 不存在，请先说明，不要自动从未知网站下载。可以建议官方仓库、winget 安装方法，或临时改用 `git grep` / `Select-String`。
