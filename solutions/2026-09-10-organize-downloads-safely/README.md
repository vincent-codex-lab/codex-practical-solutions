# 让 Codex 安全整理下载文件夹，并可一键撤销

## 今天解决什么问题

Windows 的“下载”文件夹很容易堆满图片、视频、文档和安装包。这个方案提供一个可审查的 PowerShell 脚本：默认只预览，确认后才按文件类型移动；遇到同名文件不会覆盖，并为每次实际整理生成撤销清单。

## 适合谁

- 想快速整理一个杂乱目录的 Windows 用户
- 希望让 Codex 执行重复文件操作，但需要先预览和保留撤销能力的人
- 已安装 Windows PowerShell 5.1 或 PowerShell 7 的用户

脚本不读取文件内容、不递归处理子文件夹，也不需要联网或管理员权限。

## 开始前准备

1. 下载本目录中的 `Sort-DownloadsSafely.ps1`，放到一个固定位置。
2. 先确认要整理的目录。重要文件仍建议另做备份。
3. 如果使用系统真实“下载”目录，关闭正在写入该目录的下载任务。

## 第一步：只预览

把示例路径换成自己的目标目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Sort-DownloadsSafely.ps1 -Path "D:\待整理文件"
```

预览会显示文件名和目标分类，但不会新建目录、移动或删除任何内容。

## 第二步：确认后执行

检查预览没有问题，再加上 `-Apply`：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Sort-DownloadsSafely.ps1 -Path "D:\待整理文件" -Apply
```

脚本会按扩展名放入“图片、视频、音频、文档、压缩包、安装包、其他”。如果目标分类里已经存在 `照片.jpg`，新文件会改为 `照片 (1).jpg`，不会覆盖原文件。

## 第三步：验证与撤销

执行成功后会显示撤销清单和完整撤销命令。清单保存在目标目录下的 `.codex-file-organizer-manifests` 子目录。需要恢复时运行输出的命令，例如：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Sort-DownloadsSafely.ps1 -UndoManifest "D:\待整理文件\.codex-file-organizer-manifests\清单文件.json"
```

撤销时如果原位置已经出现同名文件，脚本会跳过该项并警告，不会覆盖后来创建的内容。

## 和 Codex 一起使用

复制 [PROMPT.md](PROMPT.md) 的完整提示词，再告诉 Codex 脚本位置和目标目录。合理流程是：先预览、人工确认、执行、核对文件数，最后保留撤销清单。

## 预期结果

- 预览阶段文件数量和位置完全不变。
- 执行后，目标目录根层文件进入对应分类子目录。
- 已有同名文件保持不变。
- 再次运行不会重复整理已经位于子目录的文件。
- 使用对应清单可以把本次移动的文件恢复到原位置。

## 失败时如何处理

- “目录不存在”：检查路径和引号，不要改用整个磁盘或用户目录尝试。
- “拒绝访问”或文件正在使用：停止执行，关闭占用文件的软件后重新预览。
- 如果执行中途停止：脚本会显示已经提前生成的撤销清单；先解除文件占用，再用该清单撤销本次已完成的部分。
- 分类不符合习惯：先修改脚本顶部的扩展名列表并在副本目录测试。
- 撤销提示原位置已有同名内容：不要强制覆盖；人工比较两个文件后再决定。
- 清单丢失：不要猜测原路径或批量反向移动，改为人工检查。

## 隐私与安全

脚本只读取根层文件的名称、扩展名和路径，用于移动与记录撤销清单；它不打开文件内容、不上传数据、不访问网络。撤销清单包含本次移动文件的本地完整路径，因此不要将真实清单上传到公开仓库或聊天。

不要对同步盘、多人共享目录、正在下载的目录或没有备份的重要资料直接执行。首次使用应复制少量测试文件到临时目录验证。

## 能力边界

- 分类只依据扩展名，不识别文件真实内容；扩展名错误会被分错。
- 脚本不会识别重复文件、内容质量或保留价值，也不会删除文件。
- 默认不递归，已有子文件夹保持原样。
- 撤销只针对某一份清单记录的移动；后续人工改名或移动会导致对应项目跳过。
- 这不是备份软件，撤销清单不能替代文件备份。
