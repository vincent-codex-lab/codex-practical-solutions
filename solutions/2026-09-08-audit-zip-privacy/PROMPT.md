# 可直接复制给 Codex 的提示词

```text
请帮我检查这个 ZIP 是否适合公开上传到 GitHub：

ZIP 路径：请替换为实际路径

请严格按下面的流程执行：
1. 只读取 ZIP，不解压、不运行其中的任何程序，也不修改原文件。
2. 使用本方案中的 Audit-ZipPrivacy.ps1 扫描，并把报告保存到当前方案目录之外的临时目录。
3. 不要在回复、命令输出或报告中显示任何令牌、Cookie、密码、邮箱原文、代理凭据或个人用户名；只说明风险类型和脱敏后的压缩包内部文件名。
4. 检查文件列表中是否存在敏感配置、私钥、凭据、个人目录、绝对路径或不应公开的测试资料。
5. 将结果分为“可以继续人工复核”“发现风险，暂缓上传”“扫描不完整，需要人工处理”三类之一。
6. 如果发现问题，只提出清理建议，不要直接改写或删除 ZIP；等我明确要求后再制作清理后的副本。
7. 最后列出已检查、未检查和无法证明安全的部分，不要把“没有命中规则”说成绝对安全。
```
