# 下载文件夹太乱？让 Codex 先预览、再分类，还能撤销

下载文件夹里常常混着照片、视频、压缩包、文档和安装程序。直接让 AI “帮我整理”风险不小：它可能理解错分类，也可能覆盖同名文件。因此这次方案把安全顺序固定下来：默认只预览，确认后才移动，同名不覆盖，每次执行保留撤销清单。

## 适合谁

适合 Windows 普通用户、内容创作者和经常接收素材的小团队。需要 Windows PowerShell 5.1 或 PowerShell 7，不需要账号、管理员权限和网络。

## 准备工作

从[方案目录](../../solutions/2026-09-10-organize-downloads-safely/README.md)取得 `Sort-DownloadsSafely.ps1`，首次只在复制出来的少量测试文件上使用。不要把正在同步、正在下载或没有备份的重要目录直接作为第一次测试目标。

## 可以直接复制给 Codex 的提示词

```text
请使用 Sort-DownloadsSafely.ps1 整理我明确指定的一个 Windows 目录。先运行默认预览，不得修改文件；列出文件将进入图片、视频、音频、文档、压缩包、安装包或其他中的哪一类。只有我确认后才加 -Apply。不得递归进入子目录、不得覆盖同名文件、不得删除文件。执行后核对各分类数量，保留撤销清单并给出完整撤销命令。不要打开文件内容，不要上传文件；遇到路径、权限、符号链接或清单异常时安全停止。
```

## 操作步骤

先预览：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Sort-DownloadsSafely.ps1 -Path "D:\待整理文件"
```

确认分类计划正确后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Sort-DownloadsSafely.ps1 -Path "D:\待整理文件" -Apply
```

执行完成会打印撤销清单路径与撤销命令。把它保存好；不要把包含真实本地路径的清单公开上传。

## 预期结果

目标目录根层文件会进入对应分类子目录，已有同名文件不会被覆盖。脚本不递归处理子目录，再运行一次也不会重复移动已经整理好的文件。

## 失败处理

- 路径不存在：检查引号和路径，不要扩大到整个磁盘尝试。
- 文件被占用：关闭下载器或编辑器，重新预览后再执行。
- 执行中途停止：解除文件占用后，使用脚本提前生成并显示的撤销清单恢复已完成部分。
- 分类不符合预期：停止在预览阶段，修改扩展名规则后先用副本测试。
- 撤销发生同名冲突：脚本会跳过；人工比较后处理，禁止强制覆盖。

## 隐私与安全提醒

脚本不打开文件内容，也不联网；但撤销清单会保存本地完整路径。测试没有使用真实文件或账号。重要资料仍需独立备份，撤销清单不是备份。

## 能力边界

它只根据扩展名分类，不能判断文件内容、价值或是否重复，也不会删除垃圾文件。完整分类表、撤销方法和可复现测试见[方案说明](../../solutions/2026-09-10-organize-downloads-safely/README.md)。
